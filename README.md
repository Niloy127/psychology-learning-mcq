# Psychology of Learning — MCQ Practice

A focused, responsive MCQ practice/test website built from the uploaded NPTEL Psychology of Learning assignment questions.

## Included
- 110 questions from Weeks 0–10
- Practice mode with immediate correct/wrong feedback
- Wrong answer shows only the correct option (no explanation)
- Test mode with selectable question count and timer
- Question navigator during tests
- Results with correct/wrong/not-attempted counts
- Responsive UI for laptop and mobile
- No login, profile, streaks, dashboard, or unnecessary settings

## Files
- `index.html`
- `styles.css`
- `app.js`
- `questions.js`

Open `index.html` directly or deploy the folder to GitHub Pages/Netlify/Vercel.
